# Playtesting session notes (Sprint 4, task P3 #141)

Three short sessions with the build from P1 and the form from P2. Observe, do not coach. If a participant is completely stuck, give the smallest hint and write down exactly what was said.

## Before each session

- Tell the participant that notes are being taken and what they are used for (improving the game). Ask for their agreement before starting.
- Participant agreed to notes being taken: [ ] yes (write the participant code only, no names)
- Record the build (commit hash or date) and the machine / screen size.

## What each participant is asked to do

1. Read a puzzle (title, requirements, and instructions).
2. Change transitions using the dropdowns.
3. Press Check and interpret the feedback (Pass / Fail lines and the summary).
4. Try navigation (Previous, Next, Return to selection).
5. If they complete a puzzle, observe what happens with progression to the next one.
